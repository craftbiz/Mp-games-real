MPGAMES · PLAYER GUIDE

The Rule Book

Everything you need to know before the match.

01

The waiting room

Joining a room puts you in its player list. The room owner controls the start button. Only the owner can start a match, and the game may require a minimum number of players.

  • Check the room name, selected game, and player count before staying.
  • If the room is full, you cannot join until a place becomes available.
  • Empty rooms and abandoned waiting rooms may be automatically removed.
02

Room ownership

The owner is responsible for starting the match. If the owner leaves, the room can transfer ownership to the earliest remaining player.

  • Being the owner does not grant extra game points.
  • Other players cannot force-start a game.
  • If the room closes or the server restarts, you may need to create a new room.
03

Maths Trivia: answering

Read the entire question and choose one of the displayed answer options before the timer expires. Once you submit an answer, you cannot change it for that question.

  • Correct answer: +10 points.
  • Incorrect answer: −1 point.
  • No answer before time runs out: no answer points are awarded.
  • Questions may cover arithmetic, powers, trigonometry, complex numbers, and other enabled maths topics.

These scoring details describe the planned Maths Trivia rules. The actual game engine must enforce them; the Rule Book display alone does not implement scoring.

04

Timers and question progression

The room's settings determine how long each question lasts and when the match ends. A question can advance when all active players have answered or its timer runs out, depending on the implemented game engine.

  • Answer quickly, but make sure you select the answer you intend.
  • Late answers must not replace an already submitted answer.
  • The match may end after its question limit or time limit is reached.
05

Leaving, disconnecting, and reconnecting

This version removes disconnected players immediately. It does not reserve a place during a reconnect grace period.

  • If you close the page or lose your connection, you may be removed from the room.
  • If you return later, you may need to join again if the room is still available.
  • If the owner disconnects, ownership may move to another remaining player.
  • If the room has been deleted, create or join another room.
06

Chat and fair play

  • Keep messages respectful and relevant to the match.
  • Do not impersonate other players or spam the chat.
  • Never share your password in the room.
  • Room messages are not a private channel for sensitive information.
07

Scores and leaderboard

The platform records each player's latest result for a game and maintains a highest-score value. The displayed leaderboard depends on the saved results and the game's scoring implementation.

  • A highest score is not necessarily the same as your latest result.
  • Leaving a room does not guarantee a score will be saved; the game must submit its final result to the backend.
  • Ties should be handled consistently by the game engine.
08

Common scenarios

You're too late to answer

Your answer should remain locked out after the timer expires. The next question depends on the game engine.

The owner leaves

If players remain, the backend can transfer ownership. If nobody remains, the room may be removed.

The server restarts

Live rooms are stored in memory and will be lost. Account data and saved results are stored separately in SQLite.

The connection indicator looks stuck

A status message may not always reflect actual connectivity. If room updates stop, check the connection and try rejoining if the room still exists.

A question or result looks wrong

Report the issue to the room owner or project maintainer. A visible rule cannot correct a bug in the underlying game logic.

Game-specific settings may change how a match works.
